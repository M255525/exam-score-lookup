課程成績查詢｜使用說明

適用課程：跨境電子商務

同學怎麼查

  1. 打開查詢頁，輸入學號和姓名，按「查詢成績」。
  2. 學號和姓名都要跟作答時在測驗表單上填的一樣才查得到（全形數字、前後空白會自動處理）。
  3. 畫面會依考試分區列出每一次作答的時間戳記、系所、學號、姓名、分數。
  4. 同一場考試交了好幾次，每次都會列出並標上「第幾次」，最高分那一列會標「最高」，右上角大字也是最高分。
  5. 最高分達到 100 分會放煙火並顯示「恭喜滿分」（系統若開啟「減少動態效果」則只顯示恭喜文字）。

常用設定（右上角 ⚙）

  • 記住我的學號與姓名：預設不記住。勾選後，下次打開會自動帶入。共用電腦請不要勾。
  • 字體大小：標準／大／特大。
  • 清除本機資料：刪除這台裝置記住的學號、姓名與設定。
  • 右上角「📲 加入主畫面」可把查詢頁放到手機桌面，像 App 一樣打開。

查不到或分數有疑問

  • 先檢查學號有沒有少打或多打一碼、姓名有沒有錯字或用了不同的字（例如「台／臺」）。
  • 測驗時表單上填錯學號或姓名，這裡就查不到，請於上課期間向老師反映。
  • 成績以老師最後公告為準；資料最多約 5 分鐘後更新。

使用警語

  • 本頁僅供查詢參考，成績以老師最後公告為準。
  • 請只查詢自己的成績，勿代他人查詢或散布他人成績。
  • 在共用電腦上查詢後，請關閉分頁或清除本機資料。

老師維護說明

  • 資料直接讀 Google 表單的回覆試算表，改試算表即可，網頁不需重新部署（快取最多 5 分鐘）。
  • 新增考試（例如期末考）：在 Apps Script 的 EXAMS 加一行考試名稱、試算表 ID 與分頁名稱，重新部署同一個部署 ID；查詢結果會自動依考試分區。
  • 試算表需有「時間戳記、分數、系所、學號、姓名」欄位標題。
  • 查詢 API 只回傳學號＋姓名都相符的列，且只回傳上述五個欄位，不回傳作答內容與電子郵件；試算表本身不需要、也不應該開放「知道連結者可檢視」。
